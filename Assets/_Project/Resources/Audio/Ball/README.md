# Ball sound effects

The runtime clips in this folder are edited excerpts of CC0 recordings by Joseph Sardin, downloaded from BigSoundBank.

- `RacketHit_Soft.wav` and `RacketHit_Strong.wav`: “Badminton: racket shuttlecock” (sound 0537)
- `TennisBounce_Soft.wav` and `TennisBounce_Hard.wav`: “Tennis Ball: Bounce” (sound 0584)
- License: CC0 / public domain equivalent. Attribution is not required.
- Source: https://bigsoundbank.com/

The excerpts are generated with `Tools/Audio/ExtractBallSfx.ps1`. Runtime synthesis remains as a fallback when these Resources cannot be loaded.
